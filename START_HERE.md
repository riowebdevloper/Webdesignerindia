# WebDesignerIndia

Free, browser-only business kit generator. Creates downloadable business-card PNG, promotional-poster PNG and mini-website HTML without external APIs.

## Deploy
Use a static hosting provider that permits commercial use. Publish the repository root (`index.html`), with no build command. Configure `webdesignerindia.xyz` through GoDaddy DNS only after the hosting provider gives the exact DNS records.

## Status
MVP only. No payment gateway, billing, verified payment webhook, premium fulfillment, emails, or automatic acquisition. Do not charge until secure payment verification exists.
